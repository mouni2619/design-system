# Typography

Inter with system sans-serif fallbacks, on an eight-step scale and five weights.

## Type scale

Eight tokens from `caption` (10px) up to `h1` (30px), each carrying its own line height and letter spacing.

<TypeSpecimen />

## Font weights

Five weights from `fw-light` (300) to `fw-bold` (700).

<WeightSwatches />

## Styles matrix

Every scale token rendered at every weight.

<StyleMatrix />

## Typography color

Nine text roles, each mapped to a step on one of the palettes. Page titles inherit Grey 9 from the body color, so `h1` needs no class; the rest apply their utility.

<TextColor />
